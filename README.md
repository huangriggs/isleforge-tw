# 嶼工坊 IsleForge 3D 故事島產生器

> 本專案內容完整備份自 [https://isleforge-tw.netlify.app/](https://isleforge-tw.netlify.app/)

## 專案介紹
嶼工坊（IsleForge）是一套結合 3D 視覺與 AI 提示詞生成的教學故事島產生工具，提供島嶼九大領地、島民角色、RPG 冒險機制設定，並支援即時 3D 預覽與套件打包下載。
